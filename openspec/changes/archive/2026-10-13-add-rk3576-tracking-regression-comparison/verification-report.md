## 预解码方法与实机资格

原 256 MiB 输入缓存限制已移除，代码没有新增替代固定上限。配置版本 2 要求 `input_mode=predecode_all`，拒绝旧 `prefetch_frames` 字段。全部 1,200 帧的 Gray8 像素占 2,764,800,000 字节，约 2.575 GiB。Gray8 表示每个亮度像素占一个字节。

准备时每帧按真实行跨度复制并核对 SHA-256，之后保留在内存。SHA-256 是内容校验值，用于确认像素没有改变。解码器资源在准备结束释放。给算法的图像是独立像素副本，不允许算法写入影响后续固定输入。源集成测试在准备后临时移走编码文件，证明回放不需要再次解码。

准备、模型加载、20 秒回放及收尾都计入同一总截止。迟到预算仍为 50,000 微秒；110 秒开始停止，120 秒总上限没有放宽。准备失败不能产生有效回放时钟或进入合格集合。

指定板卡通过 adb 序列号 `5ceb49407502303d` 查询，型号为 HZ-RK3576_WuKong Board，machine ID 为 `1fe0a397f2ae4343896c7cf9d253a608`，内核 `6.1.141-rt36`，系统可见内存 8,112,044 KiB。Runtime 2.3.2、驱动 0.9.8 与运行身份和日志一致。系统 Runtime SHA-256 为 `d31fc19c85b85f6091b2bd0f6af9d962d5264a4e410bfb536402ec92bac738e8`，未被替换。

六轮均验证、供给并入队 1,200 帧，正常 EOF，没有输入缺失或队列拒收。EOF 表示输入正常结束。实际选取与消费跳过相加均为 1,200。准备耗时为 48.139～48.878 秒，总耗时 84.454～85.374 秒，最大供给迟到 18.679 ms，低于冻结的 50 ms 预算。4,730 次线程观察全部为 CPU mask `0-7`，表示允许使用全部八核。
