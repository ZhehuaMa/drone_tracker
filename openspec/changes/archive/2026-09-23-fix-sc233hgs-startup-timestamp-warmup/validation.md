## 实现及受控验证

`CameraWarmup` 按固定 2000000 微秒、120 帧、连续 8 帧推进，观察实例与正式 `CameraTiming` 实例分开。固定偏移只在开流前采样一次。观察允许相等，不允许倒退；正式输出仍严格递增。

`CameraSampleResult` 明确区分没有出队、观察丢弃、可输出帧。共同采集基类校验全部成功出队序号；观察丢弃须先归还成功。序号无符号回绕沿用既有规则。停止只唤醒采集线程，设备清理在采集线程退出后进行。新增互斥对账计数，清理失败保留未确认回收状态。

覆盖内容包括实测重复模式、第 120 帧成功、全重复耗尽、恰好到期、非法/溢出/倒退时间、策略改变、未知时钟回退、正常阶段再次重复，以及原始输出时间不被修改。设备测试覆盖观察中 OFF、停止与期限同时触达、EINTR/EAGAIN 不续期、归还失败、序号错误/回绕/缺口、部分映射失败、反复重启及失败后恢复。ROS 受控测试验证观察期间不发布框/图像，OFF 和输入失败正确收尾，恢复不重新加载模型。

容器使用 `roc-rk3576-ros2-build:humble-arm64`。执行 `./build.sh --test`，34/34 通过；另按平台 README 的 `DRONE_TRACKER_CAMERA_ONLY=ON` 入口执行独立测试，15/15 通过。容器 SDK 为 2.3.0，只是编译环境，不作为目标 Runtime 2.3.2 实机证据。日志位于 `.docker-artifacts/log/` 和 `.docker-artifacts/warmup-camera/test.log`。

## 20 分钟持续采集结果

按用户调整后的门槛，从首个合格帧的出队时刻起运行 1201.002 秒后，向本次已核对 PID 和可执行路径的工具发送 SIGINT。工具按既有逻辑写完最终报告、停止采集并释放设备。其命令退出码为 1，文本是 `Interrupted by signal; stopped and released camera`，这是本次主动缩短运行时长的已知结果，不是驱动或时间异常。帧源最终状态为 Stopped，原因为 `Stopped by caller`，没有工具超时或资源清理失败。

- 整轮时长 1201.358209 秒；资源采样跨度 1200.191948 秒。
- 合格帧 72082，全部严格递增，并逐帧符合原始驱动时间加固定偏移。
- 实测采集 60.0004 帧/秒；慢消费者每帧等待约 50 ms，消费 23746 帧。
- 入队 23777，队列满丢弃 48305，驱动序号缺口 0；出队与各处置计数对账通过。已入队但未消费的 31 帧在停止清队列时释放，不属于队列满丢弃。
- 首帧延迟 298.678 ms，相机停止耗时 12.693 ms。
- 启动 60 秒后的驻留内存在 114728960–114831360 字节之间，后段略降；线程固定 2，文件描述符固定 14。没有持续增长。
- 销毁后驻留内存 25391104 字节，线程回到 1，文件描述符回到 12。`fuser /dev/video22` 无占用，本次进程已退出。
- 系统 Runtime 指纹仍为前述固定值。长测期间同板另行编译测试副本，采集报告保留了这段竞争负载。

原始结果保存在 `sustained1805/`、`requested-stop.log` 与 `sustained-analysis.json`。目录沿用启动时名称，实际验收为用户要求的 20 分钟。任务 4.3 标记完成。

1. 预热中 OFF：合格帧、框和图像均为 0，首帧标记 unknown，阶段为 cancelled。相机停止 126.062 ms，整个节点 OFF 138.361 ms。

### 验证脚本更正与质量边界

首次 ROS 脚本使用“图像时间必须晚于发送 ON 的系统时间”判断旧帧，因驱动映射时间与系统时间存在偏差而失败，原始记录保留在 `ros-attempt1/`。这条断言超出了本变更承诺的驱动时间精度；修正版以该轮首帧身份、轮内严格递增和跨轮时间边界判断隔离，并保留系统时间差。

最终两轮首图像时间相对发送 ON 的系统时间分别早约 480.854 ms 和 486.521 ms。没有通过改时间或重采样偏移消除该差异，也未据此声称曝光同步通过。当前验证只证明既有时间策略下启动观察和严格输出规则生效；真实驱动时钟域/曝光时间精度仍需单独调查。

本次现场有效目标框为 0，保持 Detecting。输入修复、图像输出和故障恢复已通过，不据此判断目标捕获、跟踪质量、模拟内参精度或镜头成像质量通过。

最终证据包括 `ros-result.json`、`ros.log`、`ros-driver.log`、`test-final.log`、`node-ldd.txt`。测试安装仍在独立目录，正式 `/opt/drone_tracker/current` 未切换；回滚边界和旧版本启动限制不变。
