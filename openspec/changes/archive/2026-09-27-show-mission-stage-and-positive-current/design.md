# Design

## Context

实机进入拦截任务后，HUD 状态栏仍显示跟踪中；放电时电流带负号。目标是在不改跟踪算法和 ROS 接口的前提下，让状态栏按任务触发显示 `ON MISSION`，并让电流按正值读取。

节点已经订阅 `/fpv/tracker_trigger`，其中 `frame_id` 是控制字符串。目前只识别 `ON` 和 `OFF`。跟踪器处理一帧后，节点把同帧状态交给显示器；仅在状态变化时才向 `/fpv/tracker_state` 发布 `std_msgs/msg/Int8`。显示器的两条渲染路径共用布局。参考仓库在收到 `MISSION` 时仅把底部触发文字显示约两秒；本变更要求状态栏持续显示到下一次状态发布，因此不能直接复制参考仓库的限时逻辑。

## Goals / Non-Goals

**Goals:**

- 让任务文字只覆盖 HUD 状态栏，并由下一次本节点状态发布解除。
- 保持目标框的跟踪状态、颜色、锁定样式与视频帧配对。
- 对有效电流只在显示格式化时取绝对值，保留未知值处理。

**Non-Goals:**

- 不把 `TrackerState=3` 重新定义为任务状态。
- 不新增对 `/fpv/tracker_state` 的自订阅，也不改变该话题发布时机。
- 不改变跟踪算法、ROS 话题或现有 HDMI 状态切换语义。

## Decisions

### 1. 在显示管理器保存任务覆盖标志

**选择：** 触发回调收到精确字符串 `MISSION` 时，通知显示管理器置位任务覆盖标志。显示管理器在每次画面更新中把标志传给 HUD 布局。节点发布下一条跟踪状态时，同步通知显示管理器清除标志。已有锁保护显示侧事件与渲染线程的交接。

**原因：** `MISSION` 是跨帧事件，不属于单帧跟踪输出。显示管理器已经负责触发提示和重复画面更新；在此保存标志可以让无新视频帧时也及时刷新状态栏。

**未采用：** 把 `MISSION` 填入 `TrackerState=3`，会把目标丢失误报成任务执行。让 HUD 自订阅本节点的状态话题，会与进程内配对约束冲突，还会增加跨话题到达顺序的不确定性。

**实际影响：** 状态栏文字可独立变化，目标框仍由当前显示包中的真实 `TrackerState` 决定。`ON`、`OFF` 和其他字符串不置位任务标志。任务标志不因两秒触发提示结束而清除。

事件顺序示例：

1. 跟踪器输出 `Tracking=2`；节点发布状态 `2`，HUD 显示 `TRK TRACKING`。
2. 节点收到 `frame_id="MISSION"`；HUD 改为 `ON MISSION`，目标框仍按状态 `2` 绘制。
3. 后续帧继续输出状态 `2`，但节点不再发布重复状态；HUD 继续显示 `ON MISSION`。
4. 跟踪器改为 `TargetLost=3`；节点发布状态 `3`，HUD 取消覆盖并显示 `TARGET LOST`。

### 2. 在短文本格式器中取电流绝对值

**选择：** 电流通过有限值校验后，在 `CUR` 文本格式化前取绝对值。原始遥测快照仍保留有符号值。

**原因：** 用户要求的是 OSD 读数。格式器是两条渲染路径共用的唯一电流文本入口，修改范围小且不会改动原始 ROS 数据。

**未采用：** 在 ROS 接收层改写电流，会丢失原始充放电符号；在两个硬件后端各自取绝对值，则可能产生显示不一致。

**实际影响：** `-3.0 A` 和 `3.0 A` 均显示为 `CUR 03.0A`。未知或非有限值继续显示 `CUR --A`。

## Risks / Trade-offs

- **[诊断日志过量]** → 触发接收和状态发布按事件记录；HDMI 只在成功提交画面后且状态栏、目标标签或冻结状态变化时记录。日志包含轮次、帧序号和显示状态，便于把 `OFF` 与冻结提交配对。

- **[任务触发与状态发布并发]** → 显示管理器使用同一互斥锁按通知到达顺序更新标志，并用版本号唤醒渲染；定向测试覆盖先触发、后状态以及相反顺序。
- **[任务文字在停止后仍保留]** → 这是“直到下一条状态”的规则；停止和冻结提示仍在各自位置显示，目标框仍按停止规则清除。新轮首次状态发布会解除覆盖。
- **[状态栏与目标框文字短暂不同]** → 任务文字描述业务阶段，框颜色和锁定样式描述算法状态；两者有意独立。两条渲染路径使用同一布局逻辑。

## Migration Plan

先运行无硬件的事件、格式和两路径绘制测试，再在目标环境构建。生产板部署时保留当前发布目录以便回退。实机验收应发送 `ON`、`MISSION`，确认状态栏持续显示；再制造新的跟踪状态并确认恢复。另以有效负电流确认正值显示。未完成实机观察前不把本变更标为生产验收通过。
