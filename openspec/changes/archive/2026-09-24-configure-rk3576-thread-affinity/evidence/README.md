另一次按职责长测主要处于检测状态，显示 57.395 帧/秒，不作为持续跟踪的等条件替代。三次长测各约 75 秒，另有同进程三次约 5 秒切换。2071 个稳定线程样本未发现相对入口的亲和性变化。长测已接收录像帧均完成编码和写入；短切换存在一次取消，不能声称所有链路零掉帧。

验证采用临时 `LD_PRELOAD` 库识别创建职责，证明按职责分配可行。正式实现必须直接接入线程入口。测试后已恢复正式服务，未永久部署此库。未执行录像逐帧解码、光学延迟或带真值的跟踪精度评估。

这些证据用于免除重复可行性长测，不代表尚未编写的正式实现已经验收。正式实现只需按 design 和 tasks 完成定向短回归。
