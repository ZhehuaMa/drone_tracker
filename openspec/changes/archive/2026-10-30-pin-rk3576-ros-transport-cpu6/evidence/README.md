## 生产板隔离通信

运行域为 `ROS_DOMAIN_ID=182`，通信限制本机。接收端创建职责为 CPU 6，回调在 CPU 4。
独立发布进程先加入发现，再依次匹配两个不同端点，每轮发布 1100 条消息，周期 10 ms。
有界竞争辅助进程仅使用 CPU 4，每 10 ms 忙等约 7.5 ms，继承普通 nice=0，有固定退出期限。
两轮发送覆盖至少 22 秒竞争窗口；辅助进程已退出。

| 轮次 | 收到/丢失 | 回调 P50 / P95 / 最大值（ms） | DDS P50 / P95 / 最大值（ms） |
|---|---|---|---|
| 0 | 1100 / 0 | 0.265 / 0.554 / 1.163 | 0.126 / 0.151 / 0.700 |
| 1 | 1100 / 0 | 0.279 / 0.466 / 0.849 | 0.120 / 0.143 / 0.709 |

回调时延使用同一板上的单调时钟，即不会随系统校时跳变的计时来源。DDS 时延使用中间件提供的系统时钟源、接收时间之差。没有一秒及以上交付停顿。
`transport-contention.log` 保存两轮原始报告；`transport-thread-samples.json` 保存各观察窗口的线程掩码和代表性符号。
只读观察读取 `/proc`、进程栈和库符号，不附加暂停调试器，不移动线程。通过接收、事件和发现函数识别通信线程，无法识别的线程保留空符号。
共享内存接收线程使用 CPU 6；约 3.35 秒的观察窗口中等待调度 8.60–10.79 ms。线程数量是观察结果，不是绑定规则。
