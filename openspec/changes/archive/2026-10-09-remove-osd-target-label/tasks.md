# 移除 OSD 目标标签的实施任务

验证范围仅包括固定输入快照和针对性功能回归。以下任务不包含长时间稳定性测试、持续负载测试、性能测试或生产部署。软件快照不代表生产板 HDMI 实机验收。

## 1. 保存视觉基线

- [x] 1.1 保存原实现的固定输入布局快照：使用现有 `osd_hud_style_tests` 输出 HUD 和目标图层到本次独立产物目录；保存输入框、遥测、720×480 画布和固定绘制时刻，完成条件是后续能够用相同输入重现原图，不修改历史归档图。

## 2. 移除标签及调整可见文字诊断

- [x] 2.1 使两条渲染路径均不生成目标标签面板：在 `src/osd/layout.cpp` 的公共目标元素中移除标签文字、底色、边框及底板几何，移除缓存标识中的标签内容；保持目标框外扩、视频裁剪、角线和锁定装饰规则，完成条件是代码差异不改动其他 HUD 元素及硬件处理链路。
- [x] 2.2 使诊断只描述实际可见文字：在 `src/osd/layout.cpp` 将 `targetLabelText()` 统一返回空字符串，在 `src/osd/layout.h` 更新接口说明；核对 `src/osd/presenter.cpp` 保持原有日志字段格式及状态栏逻辑，完成条件是所有显示提交日志中的 `target_label` 均为空，输入标签不再参与可见文字变化判断。

## 3. 更新针对性回归检查

- [x] 3.1 覆盖标签输入变化和局部重画正确性：更新 `src/osd/tests/layout_test.cpp`，用标签为空、短文本及长文本检查同框同状态的目标输出一致；替换旧的长标签可见性断言，保留框移动、清框、边缘小框及 720×480、1280×720 画布检查，完成条件是缓存输出与完整重绘输出一致且无旧框残影。
- [x] 3.2 覆盖标签消失及其他图形保留：更新 `src/osd/tests/hud_style_test.cpp`，检查原标签区域恢复底层内容，保留各状态颜色、角框、锁定外角框、中心菱形及 `ON MISSION` 检查；完成条件是 HUD 图层与原固定输入基线一致，合成画面的差异仅位于原标签覆盖区域。
- [x] 3.3 覆盖标签移除后的提交日志：更新 `src/osd/tests/presenter_test.cpp` 的标签预期，检查正常跟踪、任务触发、停止均输出 `target_label=""`；增加仅输入标签变化的短时模拟场景，完成条件是该变化不会新增显示切换日志，且任务覆盖和停止冻结断言保留。
