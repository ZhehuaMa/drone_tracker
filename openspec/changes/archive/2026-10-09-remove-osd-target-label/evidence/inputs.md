# 固定输入快照说明

本目录保存 `remove-osd-target-label` 的软件布局快照。OSD 指视频上的屏幕信息叠加；HUD 指其中独立于目标框的遥测、状态和告警图形。这些图片由测试程序绘制，不是生产板 HDMI 截图。

## 来源与共用条件

原实现来自提交 `63cbc8e44e1a0b6d5a97de0a0357e5d294b2df2f`。修改前工作区的已跟踪文件无差异。先构建并运行该版本的 `osd_hud_style_tests`，将输出保存至 `before/`；随后修改布局与测试，使用相同输入保存至 `after/`。

完整输入及状态变化顺序可用以下命令读取，命令不会修改当前工作区：

```bash
git show 63cbc8e44e1a0b6d5a97de0a0357e5d294b2df2f:src/osd/tests/hud_style_test.cpp
```

| 项目 | 固定值 |
|---|---|
| 视频源尺寸 | 1920×1200，仅用于坐标映射，不读取真实视频 |
| 画布 | 720×480，视频区域为 `(0,14,720,450)` |
| 绘制时刻 | Unix 秒数 `1760000000`，小数秒为 0 |
| 时钟时区 | 容器 UTC，画面时间为 `08:53:20.0` |
| 飞行器名称 | `FPV` |
| 轮次 | `round=1` |
| 显示状态 | 正常与告警为 `Live`，冻结为 `Stopped` |
| 跟踪状态 | `tracker_state=2`，表示 Tracking |
| 视频存在标记 | `has_video=true` |
| 任务覆盖 | `mission_active=false`；另由测试独立检查 `ON MISSION` |

未列出的字段均保留 `PresentationState{}` 的默认值。坐标输入按原视频的像素表示，顺序为 `x,y,width,height,label`。

## 正常画面

- `sequence=100`，框为 `(1224,680,330,248,"TRACKING")`。
- 飞行状态为 `{true,true,"OFFBOARD"}`，依次表示已连接、已解锁和飞行模式。
- 姿态为 `{-2,3,214}`，依次为横滚、俯仰和航向，单位为度。
- GPS 为 `{12,3,8.3,210}`，依次为卫星数、定位等级、速度（米/秒）和运动方向（度）。定位等级 3 表示三维定位。
- 电池为 `{22.2,4.3,1.0-410.0/13000.0,410,3.7}`。依次为电压（伏）、电流（安）、剩余比例、消耗电量（毫安时）和单节电压（伏）。电池告警等级为 1。
- 解锁时长为 75 秒，高度为 102 米，温度为 31 摄氏度。
- 返航距离为 240 米，相对方向为 266 度。

花括号中的字段顺序沿用 `src/osd/presentation.h`。原标签面板映射到画布后的矩形为 `(459,229,140,38)`。

## 冻结画面

使用原测试程序后续的状态变化顺序：恢复正常输入，然后将姿态、返航方向、返航距离、电池百分比置为缺失。设置告警 `FAILSAFE`，框为 `(1400,750,240,170,"A")`，状态为 `Stopped`，触发提示为 `TRIG OFF`。序号仍为 100。目标装饰应全部清除，HUD 仍显示冻结提示及告警。
