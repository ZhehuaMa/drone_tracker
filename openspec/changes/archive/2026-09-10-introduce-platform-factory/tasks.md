## 1. 公共创建与帧源契约

本清单仅安排代码重构、源码及构建配置静态审查、平台无关编译和模拟依赖测试。Jetson 适配代码与 CMake 配置仍需修改，但不配置或编译 Jetson 目标，不运行 Jetson 程序，也不新增或执行 Jetson 专属测试。下文对 Jetson 适配行为的完成条件通过静态审查核对；它们不是实机验证结论。

- [x] 1.1 定义统一的平台创建入口，在 `src/platform/` 增加 `PlatformFactory`、输入配置和带诊断的创建结果；完成条件是声明包含帧源、帧创建器、成套模型依赖三个入口，且不含硬件 SDK 类型。
- [x] 1.2 定义可直接替换节点输入的 `FrameSource`，在 `src/platform/` 声明启动、停止、状态、尺寸、限时等待和非阻塞取帧、录像配置；完成条件是现有节点操作都有对应行为且不需要公开原生回调。
- [x] 1.3 定义只能移动的 `TrackerComponents` 及帧兼容性检查能力，在公共接口中复用两类模型后端和两类预处理器；完成条件是明确组件独占所有权、检查对象生命周期和缺失成员的初始化失败行为。

## 2. Jetson 创建与适配

- [x] 2.1 实现生产成套装配，在 `src/platform/jetson/` 复用现有 `jetson_model_factory.cpp` 和 Jetson 预处理器；完成条件是三个模型均成功且可在加载期完成的契约检查通过后才返回完整集合，错误诊断含平台、组件和路径。
- [x] 2.2 实现原队列的公共帧源适配，在 `src/platform/jetson/` 包装 `MVCamera` 和 `MVVideo`；完成条件是取帧直接委托原队列，保留容量、满队列处理、尺寸及时间戳行为，无新队列或线程。
- [x] 2.3 实现无需具体相机转换的录像配置，在 Jetson 帧源适配器中委托 `MVCamera::setup()`；完成条件是相机沿用原配置，视频输入不创建相机录像，公共节点无需认识 `MVCamera`。
- [x] 2.4 实现公共帧复制与真实类型检查，在 Jetson 适配器中包装 `VpiFrame::copyFrom()` 并提供帧兼容性验证；完成条件是保留灰度、BGR、非连续图像和微秒时间戳，不按工厂实例相等判断兼容性。

- [x] 2.5 修复 `MVCamera` 内部最小清理边界：覆盖部分初始化、已初始化但未采集、构造异常及采集线程启动失败；完成条件是按资源存在性回收、重复清理安全、线程先于其资源停止、工厂拒绝未初始化相机，且原采集队列与时间戳规则不变。通过源码逐路径审查验证，不配置或运行 Jetson。

## 3. 公共算法与业务入口迁移

- [x] 3.1 让公共跟踪器只消费注入依赖，修改 `hybrid_tracker.h/.cpp` 的创建及初始化接口；完成条件是算法中不再创建 Jetson 模型或预处理器，且所有依赖缺失都能安全失败。
- [x] 3.2 在状态变化前拒绝错配帧，替换 `HybridTrackerImp::update()` 的 VPI 强制转换；完成条件是失败返回未消费、不改变时间戳记录及计数、不缓存帧或提交检测，同时保留下游检查。
- [x] 3.3 使普通初始化失败可完整回收，调整跟踪器组装与检测线程启动顺序；完成条件是模型和公共组件就绪后才启动线程，最终销毁先等待线程再释放其使用的资源，OFF 不卸载模型。
- [x] 3.4 让节点通过统一工厂装配，修改 `drone_tracker_node.h/.cpp`；完成条件是源分类、模型路径拼接、内参计算、限时等待后取最新帧、录像和 ROS bag 行为保持不变，节点不再包含具体相机头文件或类型转换。
- [x] 3.5 让回放和压力程序使用生产创建路径，修改 `tests/replay_harness.cpp` 与 `tests/stress_main.cpp`；完成条件是通过同一平台工厂获得帧和成套依赖，保留原输入生成与压力场景。压力程序可将集合成员交给其直接使用的检测器和 NanoTrack/DCF，不必改成完整状态机。

## 5. 契约及失败路径验证

本组全部使用平台无关实现及模拟依赖，必须驱动真实公共装配辅助逻辑或真实公共调用链。模拟对象提供可控结果和资源计数，不复制生产状态机。涉及 Jetson 原生适配的部分仅进行源码静态审查，不加载 VPI、TensorRT 或其他 Jetson SDK。SDK 表示硬件开发库。

- [x] 5.1 验证公共接口和构建隔离，增加公共头文件编译检查及未实现平台选项失败用例；完成条件是无需硬件 SDK 的公共构建通过，`rk3576` 与未知值在硬件发现前失败，通过静态审查确认 Jetson 配置不要求 RKNN/RGA，不配置或编译 Jetson 目标。
- [x] 5.2 验证完整跟踪入口的错配拒绝，新增两类模拟帧及兼容性检查测试；完成条件是不兼容帧返回未消费且不触发模型调用，同时间戳后续合法帧仍可消费，独立创建器的兼容帧可用。
- [x] 5.3 验证成套创建的失败回收，为实际装配路径提供可替换创建依赖并注入 YOLO、Backbone、Head 各阶段失败；完成条件是错误身份正确、不返回半套组件、已创建资源恰好释放一次且无线程启动。
- [x] 5.4 验证初始化与销毁顺序，覆盖缺失组件、检测启动失败和检测中最终销毁；完成条件是无活动线程遗留，资源销毁发生在最后一次访问后，并保留 OFF/ON 的模型复用。
- [x] 5.5 验证公共帧源调用契约，通过模拟帧源覆盖限时等待超时、连续取最新帧、重复停止和录像配置传递；节点和测试共用 `waitForLatestFrame()` 与 `configureFrameSourceRecording()`，测试检查超时后不取帧、首帧计时回调顺序及录像开启/关闭参数。完成条件是公共调用链无额外消费者且传递参数正确，Jetson 适配的委托关系另以源码审查确认，不运行真实相机或视频程序。
- [x] 5.6 回归已有公共算法测试，运行 `model_contract_tests`、`preprocess_contract_tests`、`preprocess_common_tests` 及可独立构建的 `hybrid_tracker_tests`；完成条件是原有模型串联、输入租约、预处理数值和算法用例全部通过。
