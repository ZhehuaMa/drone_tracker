# 实施任务

本清单仅规划实施。验收限定为非断电方式，不安排拔电、断电、强制重启、碰撞或填满生产盘。新录像不包含离线转换工具或回放解码扩展。参数与验收阈值以 [design.md](design.md) 及 [录像规格](specs/rk3576-camera-recording/spec.md) 为准。

相机分流集成以前，须先完成 `fix-sc233hgs-startup-timestamp-warmup` 的实现与生产板验收。预热是交付图像前检查时间连续递增的阶段；本清单中的录像输入均指通过该边界的合格帧。主规格同步顺序为预热后录像，不能以录像条款覆盖预热规则。

## 1. 录像依赖和独立编码验证

- [x] 1.1 固定生产板录像依赖基线，在本变更目录交付 `board-recording-baseline.md`，记录指定板卡、相机节点/格式、MPP 库与头文件版本、持久挂载点、RKNN Runtime/驱动及系统库指纹；明确已有证据和未测项。
- [x] 1.2 提供独立录像构建目标，在 `src/platform/rk3576/recording/` 及对应 CMake 文件中声明 MPP 和 libavformat 依赖；完成条件是目标可独立配置，缺依赖诊断明确，公共算法与 Jetson 不传递链接这些依赖。
- [x] 1.3 实现最小硬件编码验证入口，使用合成 NV12 和既有采集边界验证原尺寸、实际帧率、色彩标记、IDR、无 B 帧及码率参数；完成条件是可输出通用工具能识别的 H.264 流，参数不支持时明确失败。
- [x] 1.4 在指定生产板运行编码兼容性验证并留存结果，确认 1920×1200 及部署实际帧率下的输入对齐、吞吐和内存；未通过时停止该配置集成，不自动改为软件编码或缩小尺寸。

## 2. 采集分流及有界原始缓冲

- [x] 2.1 定义独立录像配置与状态边界，在公共平台接口和 RK3576 工厂传递不含硬件库类型的普通数据；完成条件是旧调用默认关闭，SC233HGS 可装配新录像，AR0234 与视频拒绝启用。
- [x] 2.2 保留编码所需完整同帧画面，在 `rk3576_camera_capture_base.*` 和 SC233HGS 实现中增加可选 NV12 分流；完成条件是预热及时间检查通过后、驱动缓冲归还前只暂存候选帧有效 Y/UV 行，最终检查通过后才发布，失败则撤销，观察帧无录像像素副本，原 Gray8 输出与时间语义不变。
- [x] 2.3 实现预分配共享槽及非阻塞提交，在录像模块限制原始缓冲为至多 4 帧且不超过 64 MiB；完成条件是满时丢当前录像帧、记录区间且采集继续，关闭录像无额外像素复制。
- [x] 2.4 验证分流内容与队列隔离，扩展 `src/platform/rk3576/tests/`，覆盖行填充、色度偏移、短缓冲、色彩标记、槽满、轮次重用及录像异常；以既有 AR0234/SC233HGS 测试回归通过且跟踪输入逐字节不变为完成条件。新增色彩标记断言及相机相关七项测试均在生产板通过，见 `evidence/components/camera-recording-regression.log`。
- [x] 2.5 验证预热先于分流，使用相机重复时间序列确认观察帧不提交任一图像支路，第一个合格帧允许提交；覆盖关闭录像仍预热及暂存后归还失败、最终期限超时及停止时的撤销与终止帧身份对账。

## 3. 独立工作进程与编码流水线

- [x] 3.1 实现录像子进程启动、握手和状态通知，在录像模块采用独立工作程序及轮次协议；完成条件是准备最长等待 3 秒，通知不阻塞采集，重复 ON 不产生第二个工作进程。
- [x] 3.2 实现共享槽到编码器缓冲的所有权转移，槽在复制完成后才能复用，MPP 输入在硬件完成后才能释放；完成条件是父子进程退出或跨轮时无提前释放和旧帧混入。
- [x] 3.3 实现时间驱动的 IDR 与真实 PTS，保持原始采集时间并禁止 B 帧；完成条件是首个被录像接受的合格帧 PTS 为零，掉帧后间隔正确，IDR 无进展期限从首个合格输入到提交边界开始，预热不误报而持续拒收不能续期。
- [x] 3.4 实现至多 8 MiB 的编码输出队列，完成条件是写盘慢时停止接收新原始帧，不任意丢弃编码依赖帧，无法维持有效流时明确结束录像。
- [x] 3.5 实现父子进程异常隔离和超时收尾，完成条件是录像死亡不结束跟踪，父进程死亡会通知子进程退出，旧进程未回收时不重复创建进程或复用在用缓冲。
- [x] 3.6 验证跨进程资源生命周期，在受控测试中覆盖任意槽状态退出、进程强杀、模拟同步阻塞、父进程退出和下一轮重试；完成条件是资源不持续增长，父进程不无限等待录像。

## 4. 分段文件和周期持久化

- [x] 4.1 实现 H.264 到 MPEG-TS 的独立分段写入，在录像封装模块控制文件描述符和流参数；完成条件是默认 60 秒后的首个 IDR 切段，各段有必要参数且不依赖其他段。生产板联合运行的两段分别独立解码 3660/851 帧，切段位置为 60.980492 秒，见 `evidence/components/joint-smoke-decode.json`。
- [x] 4.2 实现应用缓冲清空和文件同步调度，完成条件是正常写盘时至多 200 ms 清空应用缓冲，按 500/1000/2000 ms 单调时间调度数据同步，同一存储路径不累积同步请求。
- [x] 4.3 实现排他创建、目录同步和正常完成标记，完成条件是文件及父目录按设计顺序同步，同名内容不覆盖，未完成会话不会被标为正常结束。
- [x] 4.4 实现附属帧时间与提交记录，在会话/帧记录中保存采集身份、PTS、视频完整帧边界及程序/模型/配置身份；完成条件是会话独立保存预热统计及有界元数据、观察帧不进入视频帧记录，提交只引用已同步视频，附属记录失败不推进提交状态。
- [x] 4.5 实现持久化健康监控，完成条件是未建立水位显示未知、以最新合格采集帧计算落后、默认周期超过 2 秒落后报告退化；从首个合格输入起持续 5 秒无进展或同步超时停止提交，预热不误触发且拒收不续期，区分最后写入和最后同步位置。
- [x] 4.6 验证存储次序与错误路径，使用注入式 I/O 覆盖短写、信号中断、设备错误、空间不足、文件/目录同步失败及视频与附属记录之间中止；完成条件是错误诊断明确、同步水位不虚增、无需制造真实磁盘故障。

## 5. 空间保护和未完成会话检查

- [x] 5.1 实现持久目录与配额检查，完成条件是绝对路径和实际本地 ext4 挂载可核验，拒绝 tmpfs/ramfs/网络路径，统计完成及未完成文件，触及 20 GiB/5 GiB 默认保护值停止录像且不删除历史证据。
- [x] 5.2 实现重启后的有限资源检查，完成条件是识别无完成标记会话、截断时间记录和最后提交位置，独立输出检查报告，不修改/转换原视频，不阻塞相机 ON，不把包结构检查表述为解码成功。独立检查器限制记录长度、文件数及报告大小；损坏尾部与最后提交边界检查已在生产板通过，见 `evidence/components/recovery-and-isolation-tests.log`。
- [x] 5.3 验证目录与证据保护，覆盖路径碰撞、低配额、外部空间变化、损坏元数据及重复重启；完成条件是旧文件内容未变、资源有界、测试不填满生产系统盘。存储注入验证动态可用空间与外部配额增长；两个独立检查进程模拟重复启动，校验原件和报告哈希不变。见 `evidence/components/latest-storage-session.log`、`evidence/components/recovery-and-isolation-tests.log`。

## 7. 非断电恢复和生产板性能验收

- [x] 7.1 验证文件中断后的完整前缀，在至少 100 个 TS 包、编码帧、同步及切段附近偏移截断测试副本；交付通用解码器结果与最后可解码时间，保留原件，不提供转换工具或修改生产回放入口。结果见 `truncation-validation.md`，共 194 个偏移。
- [x] 7.2 验证基本进程异常恢复，在指定生产板保持供电时各做一次录像子进程终止和父进程异常退出；确认跟踪连续性、资源回收及旧录像可检查，不执行大量重复实机故障测试。
- [x] 7.3 使用默认 12 Mbps、1000 ms 同步周期完成一次连续 5 分钟的跟踪/录像/OSD 联合运行，检查正常 OFF 与再次 ON、默认分段独立解码、帧数对账、零录像应用丢帧及同步落后 P99/最大值；记录可取得的资源指标与限制。此项合并原 7.5，不再执行多周期重复对照、20 轮启停和 30 分钟负载。
