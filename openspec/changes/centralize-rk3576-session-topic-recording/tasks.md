# Tasks

All items are implementation or verification work for a later apply request. None is complete merely because this planning change exists. The design has no unresolved choice that changes what is built.

Sections 1–8 retain the completed original implementation and its evidence. Sections 9–11 track the later CPU 2 installation refinement. Earlier benchmark runs used temporary thread rebinding and do not complete the new automatic-affinity tasks.
