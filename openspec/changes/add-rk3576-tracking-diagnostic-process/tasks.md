# Tasks

本清单记录实施与验收进度。只有实现和完成条件均已取得证据的任务才能勾选。缺少实机证据的任务保持未勾选。诊断采用独立进程，业务进程不新增专用日志线程。

测试时限适用于本清单全部性能、压力、负载、稳定性和故障隔离运行：单次总运行时间最多 600 秒（10 分钟），包含准备、预热、测量和收尾。涉及既有相机性能或负载契约时最多 180 秒。本清单实际计划的性能和稳定性单次预算为 150 秒，故障检查为 120 秒。均须外部截止控制；样本不足、超时或资源未回收记录失败，不延长越界，不安排实际断电或强制重启。
